# WORKTREE
## Efficiently manage your work!

Conviently organize your work on a worktree.
Every workstep relies on other steps, you can complete them until every relied step is completed.
**Add**, **Switch**, and **Complete**!

## Scheduling assistant

The web app has an AI assistant that talks to your own OpenAI-compatible model
endpoint: tell it about an event or task, ask what is planned today, or upload a
timetable photo and confirm the parsed classes. Your API key stays in this
browser; the worktree server never sees it. Configure it under Settings → AI
assistant, then open the Agent tab. See [docs/agent.md](docs/agent.md) for the
architecture and the tool contract.
